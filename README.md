# Ferretería Pfeifer 🛠️

**Ferretería Pfeifer** es una solución integral diseñada para cerrar la brecha digital en el sector de las ferreterías físicas. Esta plataforma permite modernizar la administración y expandir el alcance de pequeños y medianos negocios mediante una experiencia de compra en línea segura y eficiente.

## ✨ Características Principales

### Para los Clientes 👤
* **Catálogo Online:** Visualización de productos de ferretería con precios actualizados.
* **Carrito de Compras:** Gestión de productos antes de la transacción.
* **Pagos Seguros:** Integración nativa con **Mercado Pago** para compras fluidas.
* **Comprobantes:** Emisión automática de boletas tras la compra.

### Para los Administradores ⚙️
* **Gestión de Inventario:** Control total sobre productos, stock y categorías.
* **Seguridad Robusta:** Autenticación mediante **JWT** y control de accesos por roles.
* **Dashboard de Ventas:** Visualización de transacciones para mejorar la toma de decisiones.
